# spsport 隐私检查记录

检查日期：2026-11-01（墨尔本）。优先级：个人资料、凭据和身份信息不得随开源内容发布。

## 已处理的当前文件

- 品牌只保留 spsport，容量示例也是同一品牌。
- 删除个人署名和内部确认草稿。
- 演示身份全部改为编号，邮箱只用 `example.com`，电话号码为空。
- 不在文档中写真实仓库所有者的个人账号、联系邮箱或电脑路径。
- 演示截图重新从脱敏版本生成，人工检查可见文字；PNG 元数据单独检查。
- 不发布 `.env`、凭据、客户导出、数据库备份或本机检查报告。
- 去掉远程字体，降低演示浏览时不必要的第三方请求。

## 检查方法与结果边界

| 检查 | 覆盖内容 | 不能证明什么 |
|---|---|---|
| 本项目隐私脚本 | 常见 token、私钥、JWT、带密码连接串、非占位邮箱、本机用户路径、限制文件 | 无法识别所有姓名、地址或未知密钥格式 |
| Secretlint 推荐规则 | 当前文件及公开引用可达的历史文本内容 | 未命中不等于没有任何未知凭据 |
| 人工检查 | 品牌、演示身份、教程、可见截图与附件 | 不能清除已被别人复制的旧内容 |
| Git 元数据检查 | 作者、提交者、邮箱和提交说明 | 不会匿名化 GitHub 账号或平台活动 |
| PGlite 权限测试 | 公开数据最小化、会员之间隔离、角色访问 | 不替代真实云端 RLS/并发验收 |

初轮 Secretlint 扫描了原开发仓库主分支、旧分支和标签所涉及的 167 个历史文本对象，未报告凭据命中。自定义规则发现旧示例邮箱和提交身份信息，均应按隐私残留处理，而不能因为可能是示例就忽略。核对时，原开发仓库为私有仓库。

**旧 Git 历史尚未由本记录宣告清理完成。** 修改当前文件不会清除旧提交、旧分支或旧标签。历史替换涉及协作者克隆、分支和标签，需要单独核对目标并执行。

本次发布采用独立源码快照，不复制原开发仓库的 `.git`、旧提交、分支和标签。原私有开发历史不能直接推入公开仓库，也不能将原仓库直接改为公开。

## 当前版本的验收结果

- 自定义隐私检查与 Secretlint 扫描当前 77 个发布文件：均未命中。
- 8 组自动测试通过；包括下载 ZIP 后不依赖 Git 的隐私检查。
- TypeScript 检查与生产构建通过；依赖审计报告 0 项已知漏洞。
- 本地浏览器检查默认游客、两套容量配置、会员和管理员演示页面：可见邮箱均为占位地址，未发现第三方请求或 JavaScript 运行异常。
- 320、375、768、1280 像素宽度未发现整页横向溢出。
- 重新生成的 PNG 截图已人工检查；仅含 IHDR、IDAT、IEND 数据块，没有文本或 EXIF 元数据。
- 文档中的本地链接均能找到目标文件；静态构建包含子页面刷新回退规则。

上述结果只对应这次检查的源码和本地演示；后续提交、真实服务配置和平台自动生成的内容需要重新检查。

## 运行时加固

- 公开订场页改用最小化 RPC，不提供原始预订/订单/付款 ID。
- 原始预订只允许订单本人或员工查看；原始课程排期只允许员工查看。
- 未知的后台设置项不自动对外开放。
- 线上支付默认关闭，不能通过添加密钥或环境变量启用。

这些代码不会自动修改现有数据库；已有安装必须按部署文档执行迁移并验收。当前版本仍不适合接入真实客户资料或正式收款。

## 历史清理以后还要做什么

回读远端分支和标签，重新扫描公开引用，检查 PR/发布附件/部署产物；要求持有旧克隆的人重新克隆，并按 GitHub 官方流程处理残留缓存。无法保证撤回他人已下载的副本。

此记录只陈述实际检查范围，不承诺“绝对安全”或“整个互联网已无旧内容”。
