# spsport 本地体验与手动发布教程

这份教程按「下载 → 在电脑打开 → 体验 → 修改示例 → 分享演示」编排。每一步都有预期结果；没有完成当前步骤，就先看排错说明，不必继续复制后面的命令。

**如果你的目的是在云端后台直接部署网站，请先看 [云端部署分步指南](CLOUD_DEPLOYMENT.zh-CN.md)。** 本文是可选的本地体验和手动上传路线；不是要求用户先部署到 Lovable，再交付给客户使用。

**本教程只使用虚构数据。不要输入真实客户姓名、电话、邮箱、密码或支付密钥。** 演示站没有真实收款能力。

## 0. 先认识几个词

| 名词 | 可以怎样理解 |
|---|---|
| GitHub 仓库 | 存放项目代码和说明的网页文件夹；公开仓库里的内容别人都能看 |
| ZIP | 压缩包；下载后先解压，不能直接在压缩包里运行 |
| Node.js | 帮电脑运行这个网页项目的工具 |
| npm | 随 Node.js 安装的命令工具，用来安装依赖和启动项目 |
| 终端 / PowerShell | 输入本教程命令的窗口，和浏览器不是同一个东西 |
| 本地 | 只在你自己的电脑运行 |
| 部署 | 把网页放到托管平台，生成别人能访问的链接 |
| 数据库 | 保存真实账号和订单的地方，演示体验阶段不需要 |
| 密钥 | 程序访问服务的凭据；不能发到公开仓库、截图或聊天中 |

## 1. 下载项目

1. 在 GitHub 打开这个项目的首页。
2. 点击绿色的 **Code** 按钮。
3. 选择 **Download ZIP**，等待下载完成。
4. 解压到一个容易找到的文件夹，例如桌面的 `spsport-demo`。
5. 打开解压后的文件夹，找到 `package.json`、`README.md` 和 `src`。

**成功标志：这三个文件/文件夹在同一层。** 如果只看到另一个同名文件夹，请再打开一层。

只下载 ZIP 不会获得旧 Git 提交记录。发布源代码时仍要检查文件；下载别人的 ZIP 不等于它已经过安全审查。

## 2. 安装 Node.js

1. 打开 [Node.js 官方下载页](https://nodejs.org/en/download)。
2. 选择符合自己系统的 LTS 安装程序。本项目最低要求 **22.12.0**。
3. 完成安装后，关闭原来的终端窗口，再重新打开。
4. 在终端逐行输入：

   ```bash
   node -v
   npm -v
   ```

**成功标志：两条命令都显示版本号。** `node -v` 应是 `v22.12.0` 或更高版本。

不要从不认识的网站下载修改版安装包。如果系统提示找不到 `node` 或 `npm`，先重启终端；仍然不行，再检查是否完成安装。

## 3. 在项目文件夹打开终端

### Windows

1. 用资源管理器打开包含 `package.json` 的文件夹。
2. 在文件夹空白处右键，选择「在终端中打开」；也可以点击地址栏，输入 `cmd` 并回车。
3. 输入 `dir package.json`，确认能找到文件。

如果 PowerShell 提示不允许运行脚本，**不用修改全局安全策略**。可以改用「命令提示符」，或把后续 `npm` 写成 `npm.cmd`。

### macOS

1. 打开系统「终端」应用。
2. 输入 `cd `，注意后面有一个空格，先不要回车。
3. 把包含 `package.json` 的文件夹拖入终端，路径会自动填入。
4. 按回车，再输入 `ls package.json`。

**成功标志：能看到 `package.json`，没有“找不到文件”的提示。**

终端显示你自己的用户名或文件路径是正常的，但这些内容不要截图发到公开 Issue。

## 4. 安装并启动

在同一个终端逐行运行，上一条完成后再运行下一条：

```bash
npm ci
npm run dev
```

- `npm ci` 会按项目锁定版本下载依赖，需要网络。首次可能要等待一会儿。
- `npm run dev` 启动本地网站，终端会持续运行，不会自动回到输入提示符。
- 打开终端显示的 **Local** 地址，一般是 `http://127.0.0.1:5173`。如果端口被占用，以终端实际显示的端口为准。

**成功标志：浏览器显示 spsport 和演示预览条。**

本步骤不要复制 `.env.example`，不要注册数据库，不要填写任何密钥。没有配置数据库时，系统会自动使用演示数据。

## 5. 按这个顺序体验一次

1. 如果看到英文，点击右上角 **中文**。手机或窄窗口先打开 **Menu / 菜单**。
2. 保持 **客户** 视角，选择明天的日期，避免选到已经开始的时段。
3. 点击 **羽毛球场 1**，右侧或下方会出现时间按钮。
4. 连续点击两个可预订时间，订单摘要应合并成一段 1 小时预订。
5. 核对场地、日期、起止时间和 AUD 总价。
6. 邮箱只填写 `guest001@example.com`，姓名留空或填「演示客户 001」。
7. 点击付款按钮。演示模式应明确提示 **没有扣款、没有保存预订**。
8. 切换 **会员**，查看示例余额和会员价格；切换 **管理员**，查看示例后台。

**成功标志：流程能走通，但没有真实支付、短信、邮件或新订单。**

演示角色切换只在演示模式中出现，不能用它给真实账号管理员权限。演示设置和场地开关仅在内存中保存，刷新页面会重置；其他很多演示写操作不会保存。

### 停止和下次继续

- 停止：回到运行服务器的终端，按 `Ctrl+C`。
- 下次继续：在相同文件夹打开终端，再运行 `npm run dev`。
- 如果项目依赖没有更新，不需要每次重新运行 `npm ci`。

## 6. 发布只含示例数据的演示网站

发布前先确认：没有真实会员资料，没有 `.env`，没有收款密钥，没有你电脑或后台的私人截图。

### 先生成可以发布的网页

逐行运行：

```bash
npm run privacy:check
npm test
npm run build
```

**成功标志：隐私检查没有发现项、测试没有失败，最后出现 `dist` 文件夹。**

`dist` 是网页构建结果。`node_modules` 是开发依赖，不是要分享的网站。测试未通过时不要继续发布。

### 路线 A：使用支持手动上传的静态网站托管

例如 [Netlify 手动部署文档](https://docs.netlify.com/deploy/create-deploys/#drag-and-drop)：

1. 使用你自己的账号进入托管平台。
2. 选择手动部署/上传网站文件的入口。
3. 上传 **`dist` 文件夹**，不要上传整个工作文件夹。
4. 等待平台生成网站地址，用浏览器打开验证。
5. 不设置 Supabase 环境变量，让它保持演示模式。

项目会在 `dist/_redirects` 内生成单页应用回退规则。必须保留这个文件，否则刷新「我的预订」等子页面可能出现 404。

### 路线 B：从自己的 GitHub 仓库部署

1. 在 GitHub 点击 **Fork**，创建你自己的代码副本。
2. 在支持 Vite 的托管平台创建项目，选择自己的副本。
3. 构建命令填 `npm run build`，输出目录填 `dist`，Node 版本设为 22.12+。
4. 不设置真实数据库或支付环境变量。
5. 点击部署，完成后从首页和子页面分别刷新验证。

不同平台的菜单可能不同；找不到相同按钮时，以平台官方说明为准，不要为了赶进度上传凭据。

### 分享前最后看一遍

- 页面只有 spsport 品牌和虚构演示数据。
- 客户、会员、管理员演示视角都正常。
- 在手机上选日期、选时段、看总价可以完成。
- 页面提示预订不保存、不会扣款。
- 发布的网站不包含后台真实数据、账号资料或密钥。

公开演示中的管理员视角也是静态样例；不能接入真实会员数据库后继续开放演示切换。

## 7. 修改数量和价格

用文本编辑器打开 `venues/spsport.json`，修改对应资源的：

- `units`：场地数量，例如从 3 改成 6。
- `price_member`：会员每 **30 分钟**的基础价。
- `price_non_member`：游客每 **30 分钟**的基础价。

只改数字，不要删英文双引号、逗号或大括号。保存后本地页面会自动更新。详细例子见 [场地配置说明](VENUE_CONFIG.md)。

发布的网站不会自动跟着本地变化；修改后需重新运行检查、构建，再部署。

## 8. 如果需要真正保存订单

这已经超出演示教程。请先阅读 [后台测试配置](BACKEND_SETUP.zh-CN.md)，只用独立测试项目与虚构账号。外部付款仅说明 [Shopify 和 Stripe API 两种接入](PAYMENTS_AND_CUSTOMER_SYNC.zh-CN.md)；Shopify 客户作为主档案与后台双向关联是待实现目标。当前版本的线上支付已关闭，服务端规则和并发仍有待完善；不要直接接入客户资料或正式收款。

## 9. 常见问题

| 现象 | 先做什么 |
|---|---|
| 提示找不到 `package.json` | 回到第 3 步，进入正确的文件夹 |
| `node` 或 `npm` 不是命令 | 完成 Node 安装后重新打开终端 |
| PowerShell 拦截脚本 | 改用命令提示符或 `npm.cmd`，不关闭全局安全策略 |
| 浏览器打不开本地地址 | 终端应仍在运行；按它实际显示的地址和端口打开 |
| `npm ci` 网络失败 | 检查网络后重试；不删除锁文件，也不从陌生地址下载依赖 |
| 点了演示预订但没有订单 | 正常，演示不保存真实预订 |
| 手机看不到中文切换 | 先点击右上角菜单 |
| 刷新发布网站的子页面出现 404 | 检查 SPA 回退配置，手动上传时保留 `_redirects` |
| 安全检查不通过 | 只根据文件位置检查，不把内容原样贴进公开 Issue |
| 线上付款提示不可用 | 这是安全关闭，不是缺少密钥；不要尝试用真实密钥解锁 |

需要求助时，提供操作步骤、系统/浏览器版本、脱敏后的错误类型即可。不要提供客户资料、完整日志、密钥或个人文件路径。
